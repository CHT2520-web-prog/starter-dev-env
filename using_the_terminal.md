# Using the Terminal

Here are some basic commands that should helps us navigate our way around our Codespace using the terminal.

Remember you can use the up/down arrows keys to cycle through previous commands.

## To open/close the terminal

Enter `ctrl` + `'` to open/close the terminal.

## To stop a process e.g. stop the web server

Enter `ctrl` + `c`

## To list the contents of a directory

Enter `ls`

## To navigate to a specific directory

Enter `cd` and then the name of the directory.

If you start typing e.g. `cd PHP` and hit the tab key, the filename will be completed for you e.g. `cd PHP-basics`

## To move up one directory level

Enter `cd ../`

## To use a previous command

Use the up/down arrows to cycle through the commands you have used.
